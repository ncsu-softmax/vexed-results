# VEXED results

Public results page for **VEXED** (Vulnerability EXploit-verified Detection), a
benchmark of 207 C/C++ CVEs where a model's proof-of-concept counts only if it
crashes the vulnerable build and not the patched build.

The page compares five Claude models run through Claude Code (pass@1, 1-hour
budget, offline sandbox, ASAN-graded): overall solve rates with 95% intervals,
pairwise McNemar tests, breakdowns by tier, difficulty, project, CWE, CVSS and
publish date, failure modes, effort, and per-CVE outcomes.

View it at https://ncsu-softmax.github.io/vexed-results/ (English; a toggle
switches to Chinese).

`index.html` is generated by `evaluation/agentic/compare_models.py --site` in
the VEXED repository and is self-contained apart from d3 (cdnjs) and fonts
(Google Fonts).
